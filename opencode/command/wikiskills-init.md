Initialize the WikiSkill framework (arXiv:2608.27454) here:

1. Run: `python3 .opencode/wikiskills/wikiskills.py init`
2. Read `.opencode/wikiskills/METHODOLOGY.md` and briefly explain the three layers
   (traces / persistent wiki / versioned skills) to the user.
3. Recommend adding 1–2 validation tasks to `.wikiskills/validation/tasks.md`
   (show the template format from that file).
4. Explain the workflow: work normally — the WikiSkills opencode plugin captures
   traces automatically — then periodically run `/wikiskills-loop`.

Do not create wiki pages or skills yet; those must be earned from real traces.
